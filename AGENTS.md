# Data repository catalog

Use `data_repos.csv` as the membership list. The README maintenance policy applies to these point-in-time data collections. Do not apply Preen, add package CI or introduce a standard that requires installing environments or rebuilding every dataset.

For catalog edits, check CSV structure, repository uniqueness and agreement with README links. For changes across repositories, inspect their existing commands, preserve data and parser code, and record the reviewed commits and PRs. Keep unrelated local work intact.
